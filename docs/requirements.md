## 1. 项目背景

### 1.1 项目简介
Unmark 是一个轻量级的去水印解析网站，帮助用户快速下载无水印的抖音视频和图集内容。

### 1.2 项目目标
- **一期目标**: 实现抖音平台视频/图集的无水印解析下载
- **二期目标**: 扩展多平台支持 + 用户登录 + 付费功能

### 1.3 目标用户
- 内容创作者：需要下载素材进行二次创作
- 普通用户：希望保存喜欢的视频内容
- 运营人员：需要批量下载素材用于分析

## 2. 功能需求

### 2.1 核心功能（一期）

#### 2.1.1 链接解析
**优先级**: P0（最高）

**功能描述**:
- 用户输入抖音分享链接
- 系统自动识别链接类型（视频/图集）
- 解析并提取无水印资源

**输入**:
- 抖音分享链接（支持短链接和完整链接）
- 示例：
  - `https://v.douyin.com/xxxxx/`
  - `https://www.douyin.com/video/xxxxx`
  - `https://www.douyin.com/note/xxxxx`（图集）

**输出**:
- 视频类型：无水印视频下载链接 + 封面图 + 标题
- 图集类型：无水印图片列表 + 标题

**验收标准**:
- [ ] 支持识别抖音短链接
- [ ] 支持识别抖音完整链接
- [ ] 正确区分视频和图集类型
- [ ] 解析成功率 > 95%

#### 2.1.2 视频下载
**优先级**: P0

**功能描述**:
- 展示视频封面和标题
- 提供"下载视频"按钮
- 点击后直接下载无水印视频文件

**验收标准**:
- [ ] 视频文件无水印
- [ ] 下载速度正常（> 1MB/s）
- [ ] 支持下载进度显示

#### 2.1.3 图集下载
**优先级**: P0

**功能描述**:
- 网格展示所有图片（3列）
- 每张图片有独立保存按钮
- 提供"一键下载全部"功能

**验收标准**:
- [ ] 图片无水印
- [ ] 网格布局美观
- [ ] 批量下载功能可用

#### 2.1.4 输入验证
**优先级**: P1

**功能描述**:
- 实时验证链接格式
- 支持粘贴自动识别
- 错误提示友好

**验收标准**:
- [ ] 非抖音链接提示错误
- [ ] 空链接提示错误
- [ ] 无效链接提示错误


### 5.2 输出数据

#### 视频结果
```typescript
interface VideoResult {
  type: 'video';
  title: string;        // 视频标题
  cover: string;        // 封面图片 URL
  videoUrl: string;     // 无水印视频 URL
  author: {
    name: string;       // 作者昵称
    avatar: string;     // 作者头像
  };

```

#### 图集结果
```typescript
interface ImagesResult {
  type: 'images';
  title: string;        // 图集标题
  cover: string;        // 封面图片 URL
  images: string[];     // 无水印图片 URL 列表
  author: {
    name: string;       // 作者昵称

  };
}
```
